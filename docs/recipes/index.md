# Recipes

Recipes are complete workflows that connect the core grid API to real data and
common geospatial tools.

<div class="grid cards" markdown>

-   :material-car-emergency: **Waka Kotahi CAS crash density**

    Query public New Zealand crash points, index them in one NumPy call,
    aggregate equal-area density, and export a GeoPackage.

    [Open recipe →](cas-crash-density.md)

-   :material-vector-polygon: **Polygon to GeoPackage**

    Convert polygon data into centroid or touch-all rHEALPix coverage using the
    Python API or command line.

    [Open guide →](../guides/polygon-to-gpkg.md)

</div>

Good recipe contributions should use public or easily substituted data,
describe coordinate order and resolution choice, produce a useful artifact,
and call the public library API wherever possible.
