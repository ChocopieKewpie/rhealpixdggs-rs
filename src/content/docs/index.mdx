## The continents, expressed as cells

This globe starts with every resolution-5 cell that touches Natural Earth land,
then losslessly compacts complete groups of nine siblings into their parents.
Colour shows the stored resolution after compaction; the bright line follows
the source coastline. Toggle the complete resolution-5 grid to see what
compaction removes, then zoom in to compare the retained parent boundaries with
the full resolution-5 subdivision.

<RhealpixGlobe />

The map data is generated with the public `polygon_to_cells_intersects()`,
`compact_cells()`, and cell-boundary APIs, then compiled into PMTiles vector
archives. The browser requests only the archive header and visible tile ranges;
the uncompacted grid archive is not contacted until you select that view. No
external basemap or access token is required.

At world scale, a resolution-3 generalisation keeps the opening tile light.
The exact compacted cells stream in from zoom 2, where their additional detail
becomes visible.

## One hierarchy, two fast APIs

Every location belongs to one cell at a chosen resolution. Six root faces—`N`,
`O`, `P`, `Q`, `R`, and `S`—subdivide recursively into 3×3 groups. A canonical
identifier such as `R88756047` records the complete path through that hierarchy.

The projection is square-cell based in planar space, but its geographic
boundaries curve on the ellipsoid. Near the poles, inverse projection produces
caps, darts, and skew quadrilaterals. The library handles these shapes as part
of the grid instead of treating them as exceptional GIS features.

## A first cell

```python
import rhealpixdggs as rh

cell = rh.latlng_to_cell(-40.356, 175.611, resolution=8)
print(cell)                       # R88756047
print(rh.str_to_int(cell))        # stable integer form
print(rh.cell_to_neighbors(cell, plane=False))
```

<Aside type="caution" title="Coordinate order">
  The H3-style Python API uses `(latitude, longitude)`. The Rust API and the
  upstream-compatible object facade use `(longitude, latitude)`. Each API page
  states its convention explicitly.
</Aside>
